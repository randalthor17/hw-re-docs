## Lingbao MK75

- **Form factor:** 75% layout, 81 keys (Del, End, PgUp, PgDn, Arrows) plus a rotary encoder knob
- **Build:** ABS plastic case with double-shot PBT keycaps. Polycarbonate mounting plate on leaf-spring gaskets. 5-layer dampening.
- **Switches:** Supports both 5- and 3-pin switches. Comes with either LEOBOG Red Rabbit (linear) or LEOBOG Flower Field (tactile) switches, are hot-swappable.
- **Lighting:** 16 effects available through key combos. Features side-lighting strips (6 LEDs inside the left strip, 7 on the right) that can also be controlled using key combos. OEM software enables per-key lighting settings that save to the flash, alongside the previously mentioned features. Side lighting, however, cannot be defined outside of default effects and default couple colors, however.
- **Connectivity:** 
	- **Wired:** USB Type-C, appears as "BY Tech Gaming Keyboard" with VID:PID `258a:010c`
	- **2.4 GHz:** Connected using the OEM dongle, appears as "Compx 2.4G Wireless Receiver" with VID:PID `3554:fa09`
	- **Bluetooth:** Bluetooth 5.0 supported, appears as two devices ("MK75 3.0" and "MK75 5.0")
	- Supports Android, Win and Mac modes
- **Power:** Internal 3.7V, 4000 mAh Li-ion battery. Rotary knob features a base ring light that breathes red when charging, and is static red while not.
- **OEM ecosystem:** The hardware is the same as the AULA AU75. AULA F75 also shares the same VID:PID.
